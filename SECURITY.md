# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not** open a public GitHub issue. Instead, email **security@merge.dev** with:

- A description of the vulnerability
- Steps to reproduce
- The affected version or commit
- Any suggested mitigation, if known

We aim to acknowledge reports within 2 business days and to provide an initial assessment within 7 business days. Coordinated disclosure timelines will be agreed on a case-by-case basis.

## Scope

This policy covers the contents of this repository: skill definitions, the get-started prompt, and the prompt build script. Vulnerabilities in Merge Agent Handler itself, the Merge dashboard, or the Merge CLI should be reported through the relevant Merge channels listed at https://www.merge.dev.

## Supported Versions

Only the latest version on `main` receives security updates.
